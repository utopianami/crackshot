## 풀 문제 (한 문장)

> **Binance USDT-M 무기한선물 top50 유니버스에서, 각 코인의 BTC 대비 잔차수익률(`ret_i - β_i·ret_BTC`)을 H={4h, 8h, 24h} 앞으로 예측해 매주 상위 10 long + 하위 10 short 바스켓으로 돌렸을 때, funding 비용 뚫고 net Sharpe > 0.5 나오는 모델을 만든다.**

예측 대상 = **BTC 베타 뺀 순수 알파** (방향성 제거).
액션 = **cross-sectional 랭킹 기반 long/short 바스켓**.
승패 = **funding 반영 후 net Sharpe**.

## 문제 정의 (확정)

| 항목 | 값 |
|---|---|
| Target | `alpha_i(t, H) = ret_i(t, t+H) - β_i(t)·ret_BTC(t, t+H)` |
| β 추정 | rolling 7d WLS, BTC+ETH 2-factor (Phase 0에서 residualization 3종 ablation) |
| Universe | Binance USDT-M perp, **dynamic top 50** (월 갱신, 각 시점 상장 기준) |
| Horizon | H ∈ {4h, 8h, 24h} sweep → Phase 0에서 best 1개 선택 |
| Rebalance | **daily vs weekly sweep** (Phase 0~1.5에서 결정) |
| Label | BTC 잔차수익률의 CS rank → 5-class quantile bin |
| 기간 | 2023-01-01 ~ 2026-03-31 (LUNA/FTX 이후) |
| Candle | **5m OHLCV** (aggTrade → stream 집계) + **bookTicker 5m 경계 스냅샷** (실 체결용 bid/ask) + trade tape (microstructure 전용) |
| Funding | Binance REST `/fapi/v1/fundingRate` (실 체결액 히스토리, 1h/4h/8h 주기 자동 감지) |
| 평가 | rank IC, ICIR, long top-10/short bottom-10 **net Sharpe** (funding + ask/bid spread 반영), turnover, 4 sub-period regime split |

**Go/No-Go 게이트 (Phase 0 → Phase 1)**
1. Net Sharpe proxy > 0.3
2. 4개 sub-period 모두 net Sharpe > 0
3. Turnover < 80%/week
4. Long-only / short-only 각 net Sharpe > -0.5 (한쪽이 파괴적이면 combined도 fragile)
5. Residualization 3종 중 winner 선택 (2위 대비 +20% 차이 없으면 BTC+ETH-2f 보수 채택)

### Phase 0: ALPHA-00 — Alpha Existence Screening (모델 논의 전제)

**24h LLM 루프 ROI 최고 지점 — 여기 몰빵.**

Feature 후보 (VIF gate 전):
- **Return**: 1h / 4h / 24h / 7d raw return, BTC residual return (rolling 7d WLS)
- **Volume**: 1h·4h volume z-score, taker buy ratio, CVD slope
- **Funding**: realized funding (last 8h), rolling 30d funding mean, funding abs bucket
- **OI**: OI 1h change, OI / notional(=price × OI) ratio  (mcap 비율은 Phase 0에서 드롭 — CoinGecko free tier 365일 벽. Phase 1 진입 시 유료키 재검토)
- **Basis**: (perp - spot) / spot, basis 1h change
- **Microstructure**: Amihud illiquidity (4h), realized vol (4h, 1-bar gap), **spread_bps** (bookTicker 5m 경계), **book_imbalance** = (bid_qty - ask_qty)/(bid_qty + ask_qty)

산출물 10건:
1. Per-feature rank IC (block bootstrap SE + FDR)
2. Per-feature IC by decile (asymmetric bin 판정용)
3. VIF + feature residual autocorrelation matrix
4. 2-feature interaction IC + MLP probe IC (비선형 alpha 탐지)
5. Horizon target correlation matrix (multi-task 진입 판정)
6. Noise floor per horizon (shuffled-target null 95 percentile)
7. Portfolio proxy net Sharpe (long/short leg 분리) + turnover + 4 sub-period
8. Feature window spec YAML (Phase 0 시작 전 lock-in)
9. **Residualization ablation — 2종**: BTC-1f / BTC+ETH-2f  (mcap-weighted index residual은 Phase 0 드롭, Phase 1에서 mcap 확보 시 재도입)
10. **Regime split IC**: BTC 30d realized vol **1yr rolling median** 기준 양분 (tertile/quintile 불가 — sample size 이슈)

**진입 조건**: 개별 rank IC > 0.02 feature가 3개 이상 (H=4h 또는 8h에서), ICIR > 0.3 feature 1개 이상.
**실패 시**: Phase 1 중단, 문제 정의 재검토.
**예상 소요**: 2~3일 (데이터 확보 후).

### Phase 1: MODEL-01 — FT-T + PLE Baseline (Phase 0 통과 조건부)

- 모델: **FT-Transformer + PLE** (KOSPI에서 검증된 안정 구조, TabM sentinel 재현 회피)
- Feature: Phase 0 VIF 통과 feature만. Funding은 3채널 (rank / z-score / signed abs)
- Target: Phase 0 best horizon 1개
- Loss: Cross-entropy + label smoothing (ListMLE는 Phase 1.5 ablation)
- Stage 1 neutralize: rolling 7d WLS, BTC+ETH 2-factor
- Post-hoc: log mcap quintile 내 score rank (size exposure 제거) — Phase 0에서는 mcap 없으므로 보류; Phase 1 진입 시 mcap 확보 후 적용
- Retrain: weekly rolling (train last 90d, validation 최근 14d)
- 성공 기준: **ICIR > 0.3, Net Sharpe > 0.5** (funding 반영, survivorship 보정)
- 예상 소요: 7일

## 주요 의사결정 (회의 결론)

1. **MVP = FT-T + PLE**. iTransformer/CA-AE는 MVP에서 강등 (sentinel 원인은 아키텍처가 아니라 feature scale).
2. **Regime conditioning**: Phase 0에서 진단(split IC)만. sign-flip feature 3+ 나오면 Phase 1에서 **regime-separate 2-model** (bull/bear, BTC 30d rv 1yr rolling median 기준 switch). 단일 모델에 gating feature 추가하는 방식은 샘플 부족으로 후순위.
3. **Residualization ablation Phase 0에서 2종**: BTC-1f / BTC+ETH-2f (mcap-index는 Phase 1에서 mcap 확보 시 추가). raw return·sector residual는 5종→3종 압축 단계에서 이미 제외.
4. **24h LLM 루프 배분**: Phase 0 ≫ Phase 1 HP > Phase 2. Feature 선별이 이후 모든 Phase 비용 절감.
5. **Expert2·R3 마지막 발언 타임아웃** — R1이 대신 총정리.

## Phase 3: Walk-forward 수익성 수렴 실험 (2026-04-22~)

> 배경: v7 cs_mlp_portfolio가 **in-sample 41d** 에서는 bid/ask+funding net 양수지만,
> **h1 OOS 61d** (2025-08~09) 에서 gross +5.95% → net +2.88% (funding 중립),
> **w1 OOS 60d** (2025-05~06) 에서 gross +8.19% → net **-2.18%** (funding 파괴).
> 알파 시그널은 3 윈도우 모두에서 gross 양수지만 funding regime 변화로 net이 뒤집힘.
> 목적: **3개(혹은 2개) 윈도우에서 동시에 net 수익 내는 모델** 찾기.

### 실험 1: 펀딩 처리 + 피쳐 확장 (현 cs_mlp 아키텍처 유지)

1. 펀딩피 피쳐 투입 (current rate, past N-hour mean, CS rank, signed abs z-score) — ✅ npy_phase2에 이미 포함
2. 학습 loss에 펀딩 term: `L = L_rank + λ_fund · E[w_i · fwd_funding_4h_i]` — ✅ 완료 (2026-04-22)
3. 기존 크립토/주식 알파 논문의 피쳐 카탈로그 추가 (리서처가 수집)
4. Auto-feature (간이 버전): VIF gate + block-bootstrap IC로 후보 피쳐 자동 선별

**평가**: in-sample (41d) + h1 (61d) + w1 (60d) 모두 bid/ask+funding net PnL & Sharpe

#### 1-b 결과 (2026-04-22, λ_fund ∈ {0.5, 1.0, 2.0})

**λ_fund=2.0 선정** — 3개 윈도우 전부 bid/ask+funding net positive:

| window | bid/ask+fund sum | Sharpe | MDD | hit |
|---|---:|---:|---:|---:|
| insample | **+26.51%** | 2.88 | -22.7% | 52.4% |
| h1 | **+52.93%** | 7.68 | -9.3% | 53.5% |
| w1 | **+55.23%** | 11.41 | -5.2% | 59.7% |

비교: λ_fund=0 (이전 walk-forward baseline)에서는 w1 -2.18%로 funding drag 때문에 net 적자.
λ_fund=2.0 적용 후 w1 +55.23% → **hypothesis confirmed**: funding을 loss에 넣으면 모델이 short-on-positive-funding,
long-on-negative-funding 조합을 학습해서 total PnL에 funding 수익이 긍정 기여.

상세: `BRAIN/binance/experiments/fund_sweep_summary.md` (source)

→ 실험 1-c/1-d, 실험 2 모두 **λ_fund=2.0을 디폴트**로 고정.
