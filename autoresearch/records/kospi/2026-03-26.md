### 원인 분석

- **09:00 예측 시점**에 모델이 보는 feature = **전날 오후 2~3시 데이터** (t-200분)
- 그 사이 overnight에 미국 증시/달러/VIX가 움직였는데 모델이 전혀 모름

  - 따라서 overnight feature는 아침에 가장 중요, 오후엔 덜 중요 (자연스러운 시간 구조)

## Feature Set (4차 회의 확정, meeting_20260326_080937)

### Feature 1: overnight_gap (per-stock, enricher)

```
overnight_gap = (당일 09:00봉 시가 - 전날 15:29봉 종가) / 전날 15:29봉 종가
```
- 소스: `/shared/kospi_data/enriched_candle_vendor_from_enricher/{stock}/{date}.parquet`
- 변환: 200종목 내 cross-sectional rank (0~1)
- 파이프라인 불필요, 즉시 구현 가능

### Feature 2~5: NQ=F 일봉 OHLC 기반 path quality (yfinance)

| feature | 계산 | 논문 근거 |
|---------|------|---------|
| `nq_ret` | ln(NQ C_{D-1} / NQ C_{D-2}), expanding z-score | LIFT (ICLR 2024): NASDAQ 17h 구조적 lead |
| `nq_gk_vol` | Garman-Klass(O,H,L,C D-1), expanding z-score | ReVol: volatility 분리 +IC 0.03 |
| `nq_gap_body_align` | sign(O_{D-1}-C_{D-2}) × sign(C_{D-1}-O_{D-1}) | overnight puzzle direction signal |
| `usdkrw_ret` | ln(KRW=X C_{D-1}/C_{D-2}), expanding z-score | cross-asset orthogonal signal |

**제거된 feature (vs 3차 회의)**: sp500, growth_vs_value, vix_level, nq_body_ratio, nq_sig_area
- sp500/VIX: NQ 정보와 중복, NQ로 통합
- nq_body_ratio: gk_vol과 중복
- nq_sig_area: 일봉에서 path signature 무의미 (5분봉 필요)

### 각 Feature 의도

| feature | 의도 |
|---------|------|
| `overnight_gap` | 종목별 실제 갭 크기. 종목 간 cross-sectional 차이 포착 → alpha signal |
| `nq_ret` | 나스닥 overnight 수익률 크기. 코스피 전체 방향성 → market-level signal |
| `nq_gk_vol` | 나스닥 overnight 변동성(고-저 범위). 수익률 같아도 경로 다름 포착. whipsaw 날 높음 → 코스피 반응 불안정 |
| `nq_gap_body_align` | 갭 방향 × 바디 방향 일치 여부. clean rally → +1, whipsaw(갭업 후 반락) → -1. 방향 신뢰도 |
| `usdkrw_ret` | 달러/원 환율 변화. 외국인 자금흐름 proxy. NQ와 orthogonal cross-asset signal |

### 날짜 축 주의사항 (중요)

**한국 날짜 D의 feature = 미국 D-1일 밤 데이터**

```
예시: 한국 3월 20일 (목) KOSPI feature에 넣는 데이터
  → 미국 3월 19일 (수) ET 16:00 종가 기준
  → 한국 시간: 3월 19일 밤 ~ 3월 20일 새벽에 확정
  → 한국 9시 개장 전에 이미 확정된 데이터 ✓

코드에서:
  nq_date_index[D] = US_market_close[D-1]  # 한국 날짜 기준 -1 영업일
```

- US/한국 휴장일 불일치 주의 (미국 휴장 → forward fill, 한국 휴장 → 해당 날짜 없음)
- yfinance `NQ=F` 일봉: `Close` 컬럼이 ET 16:00 종가

### 구현 주의사항

- z-score: `rolling()` 아닌 `expanding(min_periods=30)` 사용 (look-ahead 차단)
- NQ 날짜 shift: D-1 close → KOSPI D feature, 행 단위 검증 필수
- KRW=X 방향성: 값 상승 = 달러 강세 = KOSPI 하락압력 (sign 검증 필요)
- 타임존: 미국 ET 16:00 확정 종가 = 한국 새벽 5~6시, look-ahead 없음

### 핵심 발견

1. **NQ flat feature의 구조적 실패** — 모든 종목에 동일한 NQ 값 → alpha label(market beta 제거)과 충돌. cross-sectional 정보 없음
2. **overnight_gap IC = -0.019** — 음수 IC. CS rank 변환 후에도 신호 미약
3. **NQ hourly path sig 9개 노이즈** — rank IC ≈ 0, 14개 extra feature가 FT-Trans attention 희석
4. **TabM_nq 완전 실패** — 어제와 동일 패턴, 이 데이터셋과 맞지 않음
5. **CS-MLP 105feat+c2c_120 최적 유지** — 125feat+alpha 교체 시 악화

### 근본 원인

NQ가 **flat feature**(200종목 전부 동일값)라 alpha label 학습 시 cross-sectional 분산 = 0 → 모델이 NQ 무시하거나 노이즈 학습

**해결 방향 (→ 03-27)**:
1. **섹터별 ETF 매핑** — 종목별 다른 값 할당 (반도체→SOX, 바이오→XBI). cross-sectional 분산 생성
2. **Gated MLP (FiLM)** — NQ를 modulator로. `h × (1 + tanh(gate(NQ)))`. MASTER(AAAI 2023) 구조
