## 새 방향 후보

### 방향 1: Reference 모델 자체 재학습 (Best-of-N)

현재 reference은 단일 학습 run. 10개 seed로 학습 → best 선별 → 기존보다 나을 수 있음.
- 장점: 추가 데이터/feature 불필요
- 단점: reference과 동일 feature/아키텍처 → 근본적 개선 한계

### 방향 2: 2-Stage Meta-Learning

1st stage: reference 모델 score 계산
2nd stage: score + 시장 context (NQ, sector) → refined prediction
- 장점: reference 위에 쌓는 구조 → degradation 없음
- 단점: look-ahead bias 위험, 복잡한 구현

### 방향 3: Feature Enricher 개선

Rust enricher에 overnight gap, sector relative strength 등 추가
- 장점: 가장 근본적 개선
- 단점: Rust 코드 수정 필요, NPY 재생성

### 방향 4: 다른 Prediction Horizon

현재: 120분 후 수익률 예측
시도: 60분 + 240분 multi-horizon → horizon별 전략 파라미터 최적화
- 장점: 새로운 alpha 소스
- 단점: 전략 파라미터 변경 필요

### 방향 5: 종목 필터링 (Trade Selection)

모든 종목에서 거래하지 않고, beta/sector 기반으로 유리한 종목만 선별
- 장점: alpha per trade 개선
- 단점: notional 감소, 구현이 backtest 밖
