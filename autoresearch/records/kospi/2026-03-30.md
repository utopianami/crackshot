## 실험 순서

### 실험 A: CS-MLP 강화 (최우선)

CS-MLP가 solo +11.2M으로 최강. 하지만 기본 config로 학습. 개선 여지 큼.

#### A1: CS-MLP sig111 features + full data
- 현재 CS-MLP allsec (121feat): +11.2M
- CS-MLP sig111 (111feat)은 아직 full-data 학습 안 함
- 다른 feature set → 앙상블 diversity
```yaml
모델: CS-MLP [512,256,128]
Feature: sig111 alpha (111feat)
pnl_weight: 2.0
seed: 42
```

#### A2: CS-MLP allsec 다른 seed
- seed=42 하나만 학습함. seed=0, 123으로 추가
- 2~3 seed 평균 → 더 안정적 예측
```yaml
모델: CS-MLP [512,256,128]
Feature: all_sector_beta (121feat)
seed: 0, 123
```

#### A3: CS-MLP pnl_weight sweep (full data)
- pnl_weight=2.0 (현재), 1.5, 2.5, 3.0
- 극단 예측 강도 조절 → notional 변화
```yaml
pnl_weight: [1.5, 2.5, 3.0]
```

#### A4: 최적 CS 모델들 + FT allsec ensemble
- A1~A3 best 조합으로 3~4 model ensemble 구성
- 목표: +18M+ alpha, 300M+ notional
