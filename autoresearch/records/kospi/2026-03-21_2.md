## Phase 1: Loss/Label 실험 (즉시 실행)

### 사전 분석: Alpha 분포 + IC sanity check

```
1. Alpha(return - beta) 분포 분석: mean, std, skew, kurtosis, class별 비율
2. 기존 모델 IC/ICIR 계산: feature-alpha 상관
3. IC decomposition: ic_total, ic_beta, ic_alpha_proxy
```

### 실험 계획

| # | 실험 | 구체 내용 | 평가 | 결과 |
|---|------|---------|------|------|
| 0 | **IC sanity check** | 기존 TabM enhanced pred의 IC/ICIR 계산 | IC > 0.02이면 진행 | ✅ IC=0.0759, ICIR=0.8435, >0=85.1% → Phase 1 진행 |
| 1 | **CE only (ListNet 제거)** | TabM enhanced, listnet_weight=0 | IC 비교 + trading sim + 백테스트 | ✅ IC=0.0966 (ICIR=1.15) > ListNet IC=0.0759 → CE가 IC 우위 (p≈0). 단, 백테스트 CE +16.5M < LN +27.9M. 의사결정트리: 실험 2 진행 |
| 2 | **Alpha label + CE** | c2c_120 대신 alpha(return-beta) 타겟 | IC 비교 | ✅ **IC=0.1077 ICIR=1.32** (best!) L CumAlpha +4451%, L+S +10435%. **백테스트 +30.8M alpha** (enhanced LN +27.9M 대비 +10%), sharpe 11.42, bp 25.6 |
| 3 | **CE class_weights** | 극단 class [3,1.5,0.3,1.5,3] 가중치 | IC 비교 | ✅ IC=0.1055 ICIR=1.34 (alpha-CE와 비슷), L CumAlpha +3767% (alpha-CE보다 낮음), discard |
| 4 | **Alpha label + ListNet** | alpha 타겟 + ListNet λ=0.3 | IC 비교 | ✅ IC=0.1132 ICIR=1.58 (IC 최고), 하지만 sim L +2281% WR=47% trades=40K → ListNet이 과도한 trade 생성, discard |

**의사결정 트리:**
```
실험 0: IC sanity check
  ├─ IC < 0.02 → feature 문제, Phase 1 중단, feature 재검토
  └─ IC ≥ 0.02 → 실험 1 진행
       ├─ 실험 1 (CE only) IC > 기존 → ListNet이 beta 오염원 확인
       │    └─ 실험 2 (Alpha label) → alpha 직접 예측
       └─ 실험 1 IC ≤ 기존 → ListNet이 유용, 유지
            └─ 실험 4 (Alpha label + ListNet) → target만 변경
```

**평가 프로토콜 (매 실험):**
1. val_loss + val_acc (기존)
2. **IC/ICIR** (신규): `spearman(pred_score, actual_alpha)` per timestamp → mean/std
3. **IC decomposition**: `ic_beta = spearman(pred, market_return)`, `ic_alpha = ic_total - ic_beta`
4. trading sim (기존)
5. 유망 모델은 백테스트 의뢰

### 백테스트 결과
- Alpha-CE 단독: **+30.8M alpha**, sharpe 11.42, bp 25.6
- Ens3 (alpha+ln+ce): **+31.2M alpha**, z=3.0

### 핵심 발견
1. **Alpha label이 가장 중요한 개선** — IC +42% (0.076→0.108)
2. **FT-Transformer가 TabM 대비 IC 개선** — feature interaction 학습 효과
3. **ListNet은 alpha label에서 해로움** — IC는 올려도 trading 성과 악화
4. **sr=0.1은 TabM에 소폭 도움, FT-Trans에는 무효**
5. **Feature pruning(GFS)은 임팩트 미미** — 65개 억제해도 결과 비슷
