## 실험 2: MASTER-style Gating (NQ as gate)

### 아이디어

NQ overnight을 feature로 concat하는 게 아니라 **MASTER gating**으로 사용:
- 하루 단위로 NQ overnight data → 그날의 gate α 생성
- α가 "오늘 어떤 stock feature가 중요한가"를 결정
- 다음날 NQ data 바뀌면 gate도 바뀜
- 모든 종목이 동일한 gate 공유 (시장 상황은 공통)

NQ 변동성 클 때 → gate가 안정적 feature 강조
NQ clean rally → gate가 trend/momentum feature 강조

→ alpha label과 호환: NQ가 예측값에 직접 더해지는 게 아니라 stock feature 가중치만 조절

### MASTER Gating 수식 (AAAI 2024)

```
m = NQ overnight features (모든 종목 동일, 날마다 변함)
α = F · softmax_β(W_α · m + b_α)   # F=105, β≈2~3
x̃ = α ⊙ x_base                      # element-wise gating
output = MLP(x̃)
```

- F 곱하는 이유: softmax 합=1이면 전체 feature magnitude가 줄어드므로 F배 복원 (평균 coefficient=1)
- β (temperature): 작을수록 sharp selection, 클수록 uniform. 초기값 2~3 권장

## 실험 3: MASTER-style Gating (섹터 ETF as gate) — 실험 1+2 결합

### 아이디어

실험 2의 gating 구조에 실험 1의 섹터 ETF를 결합:
- gate input = 섹터 ETF features (종목별로 다른 값)
- 반도체 종목 → SOX overnight으로 gate 생성
- 바이오 종목 → XBI overnight으로 gate 생성

→ 날마다 gate 변함 (시계열) + 섹터마다 gate 다름 (cross-sectional) → 최강 구조

```
m_i = sector_etf_features[stock_i]   # 종목별 다른 ETF
α_i = F · softmax_β(W_α · m_i + b_α)
x̃_i = α_i ⊙ x_base_i
output_i = MLP(x̃_i)
```

## 방향 A: Per-stock Beta × ETF return

### 아이디어

섹터 분류 대신 **종목별 rolling beta**로 ETF 감응도 직접 계산:

```
signal_i = Σ_k  beta_{i,k}(t) × ETF_k_overnight_ret(t)
```

- `beta_{i,k}(t)`: 종목 i의 ETF k에 대한 60일 rolling OLS beta (look-ahead 없음)
- 같은 반도체 섹터라도 SOX beta 0.8 vs 1.2이면 **다른 신호값**

구현:
- KOSPI 일봉 수익률 vs ETF 수익률 rolling OLS (60일)
- feature: `etf_beta_signal` 1개 (또는 ETF별 k개)

## 방향 C: Multi-gate (계층적 gating)

### 아이디어

NQ gate (시장 레짐) + 섹터 ETF gate (섹터 상황)를 순차 적용:

```
α_NQ    = F · softmax_β1(W1 · m_NQ)        # 시장 레짐 gate
x̃       = α_NQ ⊙ x_base                    # 1차 gating
α_sector = F · softmax_β2(W2 · m_sector)   # 섹터 gate
x̃̃        = α_sector ⊙ x̃                   # 2차 gating
output  = MLP(x̃̃)
```
