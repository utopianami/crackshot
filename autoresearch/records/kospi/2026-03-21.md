## Phase 5: Raw Candle Sequence Modeling

**목적:** rolling-aggregated feature 대신 raw OHLCV candle sequence를 직접 입력으로 사용.

**핵심 가설:**
현재 105/129feat은 rolling window(1~360분)로 최대 ~6시간의 candle 정보를 압축한 것.
Sequence 모델이 이 정보를 직접 raw candle에서 추출할 수 있고,
hand-crafted feature가 놓치는 패턴까지 학습 가능.

### 입력 설계

```
raw candle: [seq_len, 5] (O, H, L, C, V) — 종목 내 시계열
  - seq_len = 120 (2시간, c2c_120 타겟에 대응)
  - 또는 seq_len = 360 (6시간, 더 긴 컨텍스트)
  - 정규화: 종목별 temporal z-score 또는 log-return 변환
```

### 아키텍처 후보

| # | 모델 | 설명 | 장점 |
|---|------|------|------|
| SEQ-1 | **GRU + MLP head** | GRU로 candle sequence → hidden → MLP classification | 구현 간단, 이미 cs_seq_gru 있음 |
| SEQ-2 | **1D-CNN + MLP head** | Conv1D로 local pattern 추출 → MLP | 학습 빠름, parallel |
| SEQ-3 | **Transformer encoder** | Self-attention으로 candle 간 관계 학습 | 장기 의존성, 이미 cs_transformer 있음 |
| SEQ-4 | **Hybrid: Seq + Tabular** | raw candle seq → encoder → concat(tabular features) → MLP | seq + feature 결합, 가장 유망 |

### 데이터 파이프라인

```
/shared/kospi_data/enriched_candle_vendor_from_enricher/{종목}/{날짜}.parquet
  → 종목별 일별 raw candle (391 rows × 7 columns)
  → sliding window로 seq_len 길이 시퀀스 생성
  → 정규화: log(price / price[0]) for OHLC, log(vol / mean_vol) for V
  → NPY: X_seq.npy [N, seq_len, 5], X_tab.npy [N, 129] (optional), y.npy [N, 30]
```

### 이전 실험과의 차이

2026-03-19에서 sequence 모델이 실패한 이유:
- **rolling-aggregated feature를 sequence로 넣음** → 이미 temporal info가 추출된 데이터에 sequence 구조 불필요
- **이번에는 raw OHLCV candle을 직접 입력** → 모델이 feature extraction부터 학습

### 실험 계획

| # | 실험 | 구체 내용 | 결과 |
|---|------|---------|------|
| SEQ-1a | **GRU + raw candle 120** | seq_len=120, GRU-128 → [256,128] MLP → 5-class | |
| SEQ-2a | **1D-CNN + raw candle 120** | Conv1D(32,64,128) → GlobalPool → MLP | |
| SEQ-4a | **Hybrid GRU + enhanced feat** | GRU(raw 120) concat TabM(129feat) → joint MLP | |
| SEQ-4b | **Hybrid 앙상블** | SEQ-4a + TabM enhanced 앙상블 | |

### 구현 사항

1. **새 데이터 파이프라인**: raw candle → sliding window → sequence NPY 생성 스크립트
2. **Sequence trainer**: 기존 `cs_seq_gru` 수정 — raw candle 입력 모드 추가
3. **Hybrid 모델**: seq encoder + tabular encoder → concat → classification head
