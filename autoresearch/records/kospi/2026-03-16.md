## 핵심 인사이트

### 1. Epoch 0 문제 = 과적합
- [256,128] 모델은 459차원 입력에 대해 너무 커서, **1 epoch만에 과적합**
- val_loss도 epoch 0이 best → 순수한 과적합 (목표 불일치 아님)
- [64]는 작아서 epoch 2까지 학습 가능

### 2. 상관계수 분석
```
v23-v14:  0.99  (같은 arch, 같은 seed, 다른 loss → 거의 동일)
v23-v42:  0.80  (focal loss → 약간 다름)
v23-attn: 0.72  (다른 architecture)
v23-v46:  0.85  (다른 크기 → 핵심 다양성!)
v23-v38:  0.40  (freeze body → 가장 다르지만 개별 성능 약함)
```

### 3. 앙상블 성공 공식
> **큰 모델(random init, aggressive) + 작은 모델(learned, balanced) = 최적 다양성**
- 단순히 corr가 낮다고 좋은 게 아님 (v38 corr=0.40이지만 앙상블 기여 없음)
- **개별 성능이 좋으면서 다른 예측**이 핵심 → v46이 유일
