## Phase 2: Raw Candle Representation Learning

> 회의록: `alpha_squad/meetings/meeting_20260325_044727.md` (5명 전원 발언, 2라운드)

### 핵심 논점

105개 feature는 전부 raw OHLCV 200분(K200)/600분(전체)만으로 만들어졌다. 외부 정보 없음.
`모든 feature = f(raw_OHLCV[t-200:t])`. DL이 같은 raw candle로 최소한 105feat 수준을 재현할 수 있어야 한다.

### 이전 실패 원인 분석 (회의 합의)

| 원인 | 설명 |
|------|------|
| **시퀀스 길이 부족** | 이전 시도는 60 timestep. 105feat 중 120/360분 window feature 재현 불가 |
| **정규화 미비** | Raw price를 그대로 넣으면 가격 레벨만 학습 |
| **Simplicity bias** | SGD가 쉬운 feature(최근 momentum)만 학습, 복잡한 multi-step ratio에 도달 못함 (ICLR 2023) |
| **Sample efficiency** | Raw 8ch×200step=1600차원 vs K200 100K 샘플 = 1:63 비율 → overfitting 보장 |

### 회의 합의: "증거 먼저, 모델 나중"

| 제안 | 판정 |
|------|------|
| **Residual analysis + path signature IC** | **Phase 0 (kill gate)** — 전원 합의 |
| **Path signature 6개를 105feat에 추가** | **Phase 0.5** — feature 추가 > 새 모델 (전원 합의) |
| **8ch 정규화 + Conv1D + FT-Trans + 837종목** | **Phase 1** — gate 통과 시에만 |
| Anti-shortcut training (Sifer/FeAT) | **기각** — "쉬운=나쁜" 전제 금융 부적합 |
| 순수 MAE pre-training | **기각** — temporal continuity ≠ alpha-predictive |
| Feature Reconstruction Pretrain | **기각** — deterministic function approximation일 뿐 |
| IC loss | **기각** — gradient 불안정 + 변수 동시 변경 금지 |

### 실험 0: Residual Analysis (Kill Gate)

```
목적: 105feat이 놓치는 alpha-predictive 정보가 raw candle에 존재하는지 확인
방법:
  1. 105feat best model의 test set 잔차 계산: residual = alpha - prediction
  2. 잔차와 raw candle 파생 feature의 IC 측정:
     - skewness(log_return, window=20/60/120)
     - kurtosis(log_return, window=20/60/120)
     - path signature depth=2, 2D(log_return, log_vol_deviation)
       * 반드시 정규화된 입력: ch1=log(c_t/c_{t-1}), ch2=log1p(vol)-rolling_mean(log1p(vol),60)
     - vol-of-vol: rolling_std(rolling_std(log_return, 20), 60)
     - 경로 비대칭성: 전반 100분 vs 후반 100분 수익률 차이
  3. IC 측정:
     - Primary: Rank IC (Spearman) — outlier-robust
     - Secondary: Pearson IC — 방향성 확인용
     - 각 timestamp 내 cross-sectional rank 변환 후 측정
  4. 잔차 상위 5% 샘플의 raw candle 시각화 (정성 분석)

판정 기준:
  - Rank IC > 0.02 → Phase 0.5 진행
  - Rank IC 0.01~0.02 AND Pearson IC > 0.03 → 회의 재소집
  - Rank IC < 0.01 전부 → raw candle 방향 이번 사이클 종료
소요: 1~2일
전제: K200 test set + 105feat best model prediction 필요
```

|---|------|----------|------|------|
