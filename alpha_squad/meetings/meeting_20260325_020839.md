## 기존 방식 (baseline)

```
입력: 1종목 × 153 features (시점 하나)
모델: TabM, AE-MLP 등
출력: 1종목의 미래 가격 변화 예측
```

- 종목을 독립적으로 취급
- 종목 간 관계는 학습하지 않음
- feature engineering에 의존 (rolling log diff, vol rank 등)

## 제약 조건

- **primary target: c2c_120 고정**. 다른 horizon은 auxiliary loss로만 활용
- **평가 지표: CumAlpha** (beta 제거 후 누적 alpha)
  - beta = 각 timestamp에서 valid 종목의 mean(c2c_120)
  - Long alpha = return - beta, Short alpha = return + beta
- **우선순위: L CumAlpha > L+S CumAlpha > L AvgAlpha > L+S AvgAlpha**
- **sample_ratio=0.05 기본** (빠른 실험 반복). 가능성 높은 모델은 sample_ratio=0.1로 재실험
- **미래 데이터 참조 금지**: 학습/추론 시점에 알 수 없는 정보(미래 label, 미래 가격 등)를 feature나 필터에 사용하지 않는다. 새 feature/필터 추가 시 look-ahead bias 여부를 반드시 점검.

# Researcher2 (AI 아키텍처) — 회의 발언

안녕하세요, Researcher2입니다. 실험 결과와 리서치 브리핑을 종합해서 3가지 방향을 제안합니다.

---

## 1. FT-Transformer 변형 심화 — 가장 높은 ROI

실험 결과가 명확합니다. **FT-Trans large (d=192, h=6, L=4)**가 IC=0.1181로 전체 1위를 찍었고, val_loss도 최저입니다. 그런데 아직 탐색하지 않은 축이 있습니다:

**n_bins 스케일링**: 현재 TabM은 n_bins=48인데, KOSPI 전체에서 FT-Transformer는 **n_bins=96에서 최적**이었습니다 (memory 참조). KOSPI200에서도 96 또는 128로 올려볼 가치가 큽니다. PLE binning의 resolution이 올라가면 feature의 비선형 관계를 더 세밀하게 캡처합니다.

**Attention dropout + stochastic depth**: FT-Trans large가 IC는 높지만 L CumAlpha +4504%로 TabM alpha-CE의 +4451%과 비슷합니다. Overfitting 가능성이 있어요. Transformer 특화 regularization — attention dropout 0.1~0.2, stochastic depth (layer drop probability 0.1) — 을 적용하면 generalization gap을 줄일 수 있습니다. 이건 config 변경만으로 실험 가능합니다.

**구체적 제안**: FT-Trans large + n_bins=96 + attention_dropout=0.15를 첫 실험으로 돌리죠. 기존 인프라에서 config 수정만 필요합니다.

---

## 2. 앙상블 라우팅 — AlphaMix 아이디어 경량화

현재 3-seed 평균 앙상블을 하고 있는데, 실험 결과를 보면 **TabM과 FT-Transformer가 서로 다른 강점**을 보입니다:
- TabM alpha-CE: L CumAlpha +4451%, WR 71.9%, trades 6427
- FT-Trans large: IC=0.1181 (최고), L CumAlpha +4504%, trades 5928

둘의 prediction correlation이 낮다면 앙상블 이득이 큽니다. KDD 2023의 AlphaMix 논문에서 핵심은 **hyperparameter-level diversity + learned routing**인데, 우리는 이미 아키텍처-level diversity가 있으니 라우팅만 추가하면 됩니다.

**경량 구현**: inference 단계에서 simple gating — 각 모델의 최근 N일 IC를 기반으로 adaptive weight를 주는 방식. 학습 없이 rolling window statistics만으로 가능합니다. 이건 전체 KOSPI에서 검증된 Ultimate v2 앙상블(3 FT96 + 3 TabM, IC=0.1206)을 KOSPI200에 적용하는 것과 같은 맥락입니다.

---

## 3. DoubleAdapt 스타일 Domain Adapter — KOSPI→KOSPI200 전이

이게 가장 리서치 가치가 높은 방향입니다. KDD 2023 DoubleAdapt 논문(43 citations)의 핵심 아이디어:

**문제**: 전체 KOSPI(837종목)로 학습한 모델을 KOSPI200에 직접 적용하면 distribution shift가 발생합니다. 대형주 위주의 KOSPI200은 feature 분포가 다릅니다 — volatility가 낮고, momentum factor의 반감기가 길고, 유동성 feature의 range가 좁습니다.

**해결**: Lightweight data adapter (small MLP)를 feature pipeline 뒤에 붙여서, KOSPI200의 feature 분포를 full-KOSPI 학습 분포에 맞추는 것입니다. 핵심은 **본 모델은 freeze하고 adapter만 학습**하므로 overfitting 위험이 낮습니다.

**구체적으로**: 
1. Full KOSPI에서 학습된 best model (TabM alpha-CE 또는 FT-Trans large) freeze
2. 2-layer MLP adapter (hidden=64) 추가, KOSPI200 데이터로만 adapter 학습
3. 학습량이 적으므로 수렴이 빠르고, 원본 모델의 지식을 보존

다만 이건 새 trainer 구현이 필요하니 Phase 2로 미루고, 먼저 1번(FT-Trans 튜닝)과 2번(앙상블)을 진행하는 게 맞습니다.

---

## Raw Candle Representation Learning — 솔직한 의견

이전 세션(#S2903)의 분석과 제 리서치 결과가 일치합니다: **daily 수준에서 raw candle learning은 ROI가 낮습니다.** 이유:

1. **정보 밀도**: OHLCV 5개 값 × 1일 = 극히 낮은 information density. 153개 engineered features가 이미 이 정보를 압축하고 있음
2. **비정상성**: raw price pattern은 regime마다 의미가 달라짐. 2024년의 candle pattern이 2025년에 동일하게 작동한다는 보장 없음
3. **업계 합의**: Renaissance, DE Shaw 등이 daily prediction에서 engineered features를 선호하는 이유가 있음

KDD 2025의 stock-specific pre-training 논문이 있긴 하지만, TSFM-Bench가 보여주듯 **financial time series에서 foundation model의 일반화 성능은 아직 불확실**합니다.

**유일한 가능성**: 1분봉 raw sequence를 Conv1D로 encoding해서 153 features와 concat하는 multi-modal 방식. 그런데 이것도 추가 정보량 대비 복잡도 증가가 큰지 검증이 필요합니다.

## 즉시 실행 가능한 실험 3개

**실험 A: FT-Trans large + n_bins=96**
- 전체 KOSPI에서 n_bins=96이 최적이었음 (memory 확인됨)
- KOSPI200에서 아직 48로만 돌림 → resolution 부족 가능성
- config 한 줄 변경: `n_bins: 96`

**실험 B: FT-Trans + ListNet λ=0.3 (alpha label 유지)**
- 현재 FT-Trans는 CE-only. TabM에서 alpha+ListNet이 IC=0.1132 (CE보다 높음)이었으나 WR이 47%로 폭락
- FT-Trans의 attention 구조가 ListNet의 cross-sectional signal을 더 잘 활용할 수 있음
- **가설: FT-Trans + alpha + ListNet에서는 WR 하락 없이 IC 향상 가능**

**실험 C: Ultimate v2 앙상블 (3×FT96 + 3×TabM)**
- 전체 KOSPI에서 IC=0.1206, WR=73.2% 달성한 조합
- KOSPI200 데이터로 동일 구성 재현
- 개별 모델 IC 0.11대 → 앙상블로 0.12+ 기대

## DoubleAdapt은 Phase 2로

솔직히 **위 3개 실험만으로 충분히 돌파 가능**합니다. FT-Trans large의 IC=0.1181이 이미 전체 KOSPI의 Ultimate v2 (IC=0.1206)에 근접합니다. n_bins=96 + 앙상블이면 **0.12 돌파는 현실적**입니다.

DoubleAdapt domain adapter는 위 실험들이 plateau에 도달한 후에 투입하는 게 맞습니다. 현 단계에서 새 trainer를 짜는 건 over-engineering입니다.

## FT-Trans n_bins=96의 이론적 근거 보강

단순히 "전체 KOSPI에서 96이 좋았으니까"가 아니라, **왜 96이 48보다 나은지** 메커니즘을 짚겠습니다.

PLE(Piecewise Linear Encoding)에서 n_bins는 **continuous feature를 discrete representation으로 변환하는 resolution**입니다. KOSPI200은 전체 KOSPI 대비:
- 종목 수 4배 적음 (200 vs 837) → cross-section이 좁음
- 대형주 편향 → feature 분포의 tail이 얇음
- 그런데 **feature 간 미세한 차이가 종목 구분에 더 중요해짐**

bins=48이면 feature값 range를 48등분하는데, 대형주끼리는 feature 값이 비슷하니 **같은 bin에 몰리는 collision이 잦습니다**. bins=96이면 이 collision을 절반으로 줄여서 개별 종목의 feature 특성을 더 정밀하게 구분합니다. FT-Trans의 attention이 이 정밀한 embedding 위에서 작동하니 **interaction quality도 동반 상승**합니다.

반면 bins=128+는 KOSPI200의 200종목으로는 overfitting 위험. **96이 sweet spot일 가능성이 높습니다.**

---

## 한 가지 리스크 플래그

FT-Trans large (d=192, h=6, L=4)의 **파라미터 수**가 TabM 대비 상당히 큽니다. n_bins=96으로 올리면 embedding layer 크기도 비례 증가합니다. KOSPI200의 학습 데이터가 전체 KOSPI의 ~24%(200/837)이므로, **data-to-parameter ratio가 급격히 나빠질 수 있습니다.**

대응 방안:
- **sample_ratio=0.1로 올려서 데이터 보충** (sr=0.1이 이미 검증됨)
- **weight_decay를 0.02→0.05로 강화**
- 또는 **d=128, h=4, L=3으로 축소한 medium 모델**도 병행 검토

이 부분은 Expert분들의 실전 감각이 필요합니다. 파라미터 대비 데이터가 충분한지, regularization으로 커버 가능한지.
