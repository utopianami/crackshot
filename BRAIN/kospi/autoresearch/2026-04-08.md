## 2. 학습 재현성 검증 + XLA deterministic flag

### 관찰
- 같은 config, 같은 seed=42 (default), 같은 NPY로 cs_mlp 여러 번 학습 → 매번 **다른 weights (md5 다름)** + 다른 backtest alpha
- 최소 3 run에서 NEW backtest alpha 범위: -1.01M ~ +1.77M (2.78M spread)

### 진단

**Minimal JAX 테스트** (det_test_minimal.py): Linear(10→5), 100 샘플, 3 iter → 2 run bit-exact. **JAX 자체는 정상**.

**cs_mlp_det_tiny** (CS-MLP [64,32], 2 epoch, sample_ratio 0.002): 2 run 비교
- epoch 0 batch 1, 2: 완전 동일
- **epoch 0 batch 3부터 1e-7 diff 시작**
- epoch 1 batch 1: 3e-4 diff (~2500배 증폭)
- 이후 exponential amplification → 다른 local minimum 수렴

### 원인
**GPU parallel reduction 순서 비결정성**. 큰 텐서(cs_mlp의 [32 ts × 200 stocks × 300 feat] = ~1.9M 원소)의 sum/mean 연산이 thread scheduling에 따라 다른 순서로 부분합 → 1e-7 수준 차이 → SGD가 chaotic amplify → 다른 weights.

Minimal test에선 reduction 크기가 임계 아래라 결정적. cs_mlp는 임계 이상.

### 수리
`XLA_FLAGS="--xla_gpu_deterministic_ops=true"` 환경변수.

**`scripts/train.py`에 자동 주입**:
```python
import os
if os.environ.get("DISABLE_DETERMINISM") != "1":
    _existing = os.environ.get("XLA_FLAGS", "")
    _det_flag = "--xla_gpu_deterministic_ops=true"
    if _det_flag not in _existing:
        os.environ["XLA_FLAGS"] = f"{_existing} {_det_flag}".strip()

import argparse
# ... rest of imports
```

비용: **학습 속도 5.9배 느림** (2 epoch 74s → 434s). patience 넘어서면 시간 더 들 수 있음.

### 검증
`cs_mlp_det_short.yaml` (2 epoch) × 2 run:
- flag 켠 상태로 loss **bit-exact** 동일 (epoch 0 ~ epoch 1 batch 10 전부)
- md5 완전 동일: `4581467309ae31af618e7ec7c3698998`
- backtest alpha 완전 동일

즉 flag 켜면 재현성 확보. 바로 쓸 수 있는 상태.

`DISABLE_DETERMINISM=1` 로 override 가능 (속도 필요 시).

- **NEW만 이상한 이유**: wScore4 + 나머지 전부 켠 조합이 compound → variance 폭발
